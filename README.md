#Cinestream

cine-stream is a modern and responsive movie discovery website. Users can browse movies, search by title or genre, filter the collection, view movie details, switch between light and dark themes, and subscribe to a newsletter.

## Features

- Featured movie hero section
- Movie collection grid
- Search movies by title or genre
- Genre filters:
  - All
  - Action
  - Drama
  - Sci-Fi
  - Comedy
  - Thriller
- Movie details modal
- Light and dark theme toggle
- Add-to-list button interaction
- Newsletter subscription 
- Responsive design for desktop, tablet, and mobile devices
- External movie artwork loaded from Unsplash

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash image URLs
